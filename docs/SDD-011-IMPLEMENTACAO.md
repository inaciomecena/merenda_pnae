# SDD-011 - Implementação

Backend: módulo `oportunidades-pnae`, serviço `OportunidadesPnaeService`, DTOs e controller versionado. Endpoints: `GET /produtor/minhas-oportunidades`, `GET /produtor/minhas-oportunidades/:chamadaId:itemId`, `GET /produtor/minhas-oportunidades/resumo`, `POST /produtor/minhas-oportunidades/:id/interesse`, `PATCH /produtor/minhas-oportunidades/interesse/:id` e `GET /produtor/meus-interesses`.

Frontend: aba Oportunidades PNAE em `/meu-campo`, com filtro de compatibilidade, pendências, motivos e manifestação real. Não há botão de proposta formal.
