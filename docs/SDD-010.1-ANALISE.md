# SDD-010.1 - Auditoria funcional

| Funcionalidade | Existente | Lacuna | Ação |
|---|---|---|---|
| Unidades | API completa | edição ausente na UI | formulário PATCH com versão |
| Produtos | API completa | edição/capacidade ausente na UI | formulário PATCH compatível |
| Logística | API completa | edição ausente na UI | formulário PATCH com versão |
| Sazonalidade | mês e safra | ano e unidade | migração aditiva e filtros |
| Disponibilidade | saldo confirmado | reservas reais ainda dependentes de operação | manter bloqueio manual |
| Listagens | arrays sem paginação | filtros/paginação | resposta paginada opt-in |
| Catálogo | ProdutoReferencia e nutrição | melhorias de busca pendentes | preservar catálogo central |

Registros legados de sazonalidade permanecem com `anoReferencia = NULL`; nenhum ano é inferido.
