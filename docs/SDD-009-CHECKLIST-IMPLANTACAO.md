# SDD-009 - Checklist de implantação

Checklist padrão criado pela API para cada instituição:

- Dados institucionais
- Usuários e vínculos
- Permissões
- Templates
- Parâmetros
- Auditoria
- Backup
- Testes
- Aceite institucional

Cada item possui situação, evidência, responsável, prazo, observação e pendência. O estado `HOMOLOGADO_OPERACIONALMENTE` só é aceito quando todos os itens estão `CONCLUIDO`. O relatório também explicita que aceite técnico não substitui aceite institucional.

Não foi criado aceite fictício nem autorização de produção.
