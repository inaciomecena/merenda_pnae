# SDD-010.1 - Requisitos atendidos

- Edição de unidades, produtos e logística no painel `/meu-campo`.
- Controle otimista por `versao` preservado.
- Sazonalidade diferenciada por ano e unidade produtiva.
- Paginação opt-in para produtos, safras e sazonalidade.
- Arrays legados preservados quando `pagina` não é informado.
- Nenhuma reserva ou proposta automática criada.
