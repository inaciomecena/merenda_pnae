# SDD-010 - Catálogo de produtos

O catálogo existente `ProdutoReferencia` foi ampliado com unidade de referência, apresentação, armazenamento, refrigeração, fonte técnica e status de validação. Sinônimos e palavras-chave existentes continuam disponíveis.

Informações nutricionais ficam em tabela própria, com fonte, versão, data, estado do alimento e validação. O sistema não preenche ausências com zero e não afirma que o valor é laudo do produtor.

Solicitações de novos produtos são administrativas e não ativam automaticamente um item no catálogo.
